📖 使用說明

手機掃碼 → 照片直接傳到大螢幕 → 自動去背 → 祈福繪馬牆與星空

① 開始前（只需做一次）

  1. 手機掃碼要打開的是這份網頁，所以請先把本檔案放到免費靜態網站空間（例如 GitHub Pages、Netlify），取得網址。
  2. 在大螢幕電腦用瀏覽器（建議 Chrome / Edge）開啟該網址。
  3. 若你是雙擊檔案或用 localhost 開啟，請按右下角「⚙ 網址」，貼上部署後的網址並按「套用」，QR Code 才會正確。
  4. QR Code 與連線狀態在右下角，顯示「已就緒，等待手機連線」即可開始。選單與 QR Code 平時會隱藏，滑鼠移到畫面最上緣即可叫出。

② 手機傳照片

  1. 用手機相機或瀏覽器掃描右下角 QR Code（或按「🔗 複製網址」傳給對方）。
  2. 頁面顯示「✅ 已連線到大螢幕」後，點中間的框，選擇拍照或從相簿選取。
  3. 選一張：先預覽，再按「加入照片牆」。選多張：會自動逐張送出。
  4. 看到「已送到照片牆」就完成了，照片會自動去除白色背景並出現在大螢幕上。

拍攝建議：把物品或人像放在白色背景前，去背效果最好。

③ 大螢幕上的操作

  • 🖼 本機選圖或把圖片直接拖曳到畫面：在大螢幕電腦上直接加入照片。
  • 祈福繪馬牆：每張照片會畫在一塊木製繪馬上，掛在牆上輕輕搖擺；新照片會「啪」地掛上。繪馬以小尺寸掛在牆上，照片很多時會自動再縮小，超過畫面可用滑鼠滾輪往下捲。
  • 點擊放大：點任一塊繪馬可放大觀看照片與掛上時間；按 ←／→ 切換上一張／下一張，點擊任意處或按 Esc 關閉。
  • 更換背景：控制列的背景選單可切換星空夜、銀河、黃昏星空、神社夜、純黑、自選顏色或自訂圖片；「🖼 背景圖」可選自己的圖片，「✨ 星星」可開關星空特效。設定會記在這個瀏覽器。
  • 衝場動畫：每 3 分鐘自動觸發，每塊繪馬會從牆上取下，由左向右飛過畫面，再掛回牆上；也可在選單按「立即衝場」手動觸發。
  • 選單自動隱藏：開啟後前 20 秒會顯示標題、倒數、音樂控制與 QR Code，之後自動隱藏。把滑鼠移到畫面最上緣即可再次顯示（離開後約 2.5 秒收起）。按鍵盤 H 可固定顯示或取消固定。
  • 清空：按控制列的紅色清空按鈕，可刪除所有照片（無法復原）。

④ 背景音樂

  • 下拉選單可選「🎵 輕快歡樂」或「🌅 晨光（內建合成旋律，不需網路）」。
  • 📁 本機音樂：選擇自己電腦裡的音樂檔，可多選，加入後自動播放。
  • 🔗 網址：貼上音樂檔直連網址（需允許跨來源存取，否則會顯示「載入失敗」）。
  • 按「播放音樂」開始或暫停；瀏覽器規定需先點擊頁面才會出聲。星空會隨音樂閃爍，並偶爾劃過流星。

⑤ 常見問題

  • 手機顯示「找不到大螢幕」：請確認大螢幕頁面保持開啟、QR Code 是最新的；頁面會每 3 秒自動重試。
  • 一直連不上：部分場地網路會封鎖點對點連線，請換用手機行動網路或其他 Wi‑Fi 再試。
  • QR Code 突然變了：舊連線 ID 仍被占用時會自動換新 ID，請重新掃描。
  • 沒有聲音：先點一下頁面並按「播放音樂」；音樂網址失效時請改用「本機音樂」。

⑥ 注意事項

  • 大螢幕頁面關閉後，手機就無法上傳。
  • 照片只儲存在大螢幕電腦的這個瀏覽器；換瀏覽器或清除網站資料，照片會消失。
  • 任何拿到 QR Code 的人都能傳照片，活動結束後建議清空照片。
